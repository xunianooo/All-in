# All In 1.2.29-test（35）Trae 剩余积分显示修复

此说明对应当前测试版源码；本轮只同步代码，不发布APK或创建Release。沿用1.2.28-test的网页登录修复；参考源码继续固定在2026-11-13用户确认的本地版本，未另行更新。

## 修复

- Trae上游返回总额度、已用额度；网关现在同时输出统一的remaining/total字段，不再让面板只能显示账号与时间。
- 剩余积分在汇总原始额度后先做减法，再按界面精度舍入；保留旧used/amount/limit字段兼容既有读取方。
- 面板兼容旧版Trae额度窗口；支持不限额标记和到期时间字段。
- 明确的零额度显示0；没有有效积分套餐的数据仍为未知，不捏造0；超额使用时剩余下限为0。
- 只调整额度解析与显示，不重新登录、强制刷新凭据或自动签到。

## 验证范围

新增回归先复现旧面板有额度字段却返回空文字，修复后通过；包含实际DOM渲染、额度窗口标准化、舍入、零值、无限额及未知值断言。登录修复的68项检查同时重跑通过。

最终构建、签名及设备结果以交付目录ARTIFACTS.json和本地验证记录为准。真实余额是刷新时快照，会随供应商服务和账户使用变化。
