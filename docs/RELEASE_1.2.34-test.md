# 1.2.34-test（40）本地修复说明

修正 ZCode 赠送请求与固定本地 3.17.2 上游契约不一致的问题。未更新上游、未提交上传或公开发版。

## 改动

- 同步当前声明版本的六段模板，修正日期前缀、环境段空白/说明、模型说明位置及可选 Skill 指引。
- 仅赠送封装按已登录账号的真实设备/会话填写 metadata；保留其他 metadata 字段，非赠送的 caller metadata 规则不变。
- 账号/设备标识、拒绝保护、计费通道选择和付费 Key 未改动。
- 独立测试基准来自固定本地上游 JSON 数据，并以公开已知哈希校验；不是从旧网关常量自造预期。

## 当前验证

- 旧版已由新测试复现失败；修正后差分 37 项通过。
- 15 个相关 JVM/回环 HTTP 执行任务、面板 35/35 通过；原生协议和原签到判定回归未退化。
- 原证书 v2/v3、包名/版本、CRC、打包页面及新版模板入包核对通过。
- 指定 5580 保留配置/管理身份/UID/10 账号由 39→40 覆盖升级。
- 测试机DNS失效已通过原AVD网络后端重启恢复，数据未清除。
- 真实默认非流式、SSE、工具调用及结果回传均HTTP200/zcode-gift通过，4成功请求usage合计4954，对应赠送计数减少4954。
- 一条额外强制reasoning_effort=none请求返回1210；去掉可选参数、保持模型/128输出上限/非流式模式后成功。默认通道已验证，不称所有额外参数组合都可用；未静默改客户端意图。

新安装包仅本地验收。外部手机、OEM、长期和所有模型未因此获得完整覆盖。
