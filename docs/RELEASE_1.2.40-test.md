# 1.2.40-test（46）账号 JSON 文件迁移

此页记录46版的本地开发与测试阶段；这些功能已并入[1.2.41 正式版（47）](RELEASE_1.2.41-test.md)。46版安装包仍作为原本地历史交付保留，以下测试保留原版本归属。

## 功能

- 供应商账号卡片的「导入账号」「导出账号」接通 Android 系统文件选择与保存，不再把复制/弹窗展示凭据当作文件导出。
- 选择单个、多个或跨供应商账号/独立Key；输出版本化 JSON，实际写入并读回校验后才报成功。
- 支持 All In 标准/历史账号文件、对应 OpenCode/Magpie 认证字典、Codex auth.json，以及已核对的 ZCode/Antigravity/Qoder 特殊结构。
- 混合文件自动分类，未知记录可明确指定供应商或跳过；显示新增/重复/待更新/无效条目，更新现有资料需要额外确认。
- 账号、刷新与设备资料成组保留；配置变更时拒绝过期预览；确认批次原子持久化，失败不污染现有内存账号。
- 保留停用标记、相关刷新未知/已消费保护及签到防重放，不伪造登录有效或官方领取成功。

完整格式、用法及限制见[账号文件说明](ACCOUNT_JSON_TRANSFER.md)。当前文件功能限 Android 应用内；浏览器页明确提示，不自动复制或暴露凭据。

## 本轮测试

- 完整249个JVM/本地HTTP测试执行任务全部通过；不等同249个独立业务场景。
- 新迁移检查：格式96、合并52、实际持久化/故障/刷新保护32，共180条。
- 页面39/39；Android API34运行时36/36；Release Lint 0 Error /116 Warning。
- 实际 Android 系统“另存为”生成下载目录 JSON，再从系统文件选择器导回。3家供应商4条记录正确分池，刷新字段、停用账号/Key及全局配置核验通过。
- 重复导入、取消及模拟提交失败均保留原配置，失败不产生成功回执。
- 所有文件往返采用隔离合成数据，没有导出真实账户文件或消费真实供应商推理/领取。

本次发现并修复：通用登录保存失败时会保留可能已消费的凭据，这不适用于纯本地导入。新增账号迁移使用先落盘后发布内存的独立事务路径，不改变原登录/续期故障保护。

签名包用原证书，保留旧版本产物。调试文件测试入口只在debug源集，不进入Release。未运行云端CI、未更新固定上游、未操作日常模拟器或清理用户账号。第三方未知格式、全模型/设备/国际团队与长时场景不作全覆盖承诺。
