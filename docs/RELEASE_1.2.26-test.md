# All In 1.2.26-test（versionCode 32）

本次发布包含自1.2.23-test以来尚未上传的累计修复，不只包含最后一轮额度改动。仍为预发布测试版。

## 主要变更

- 修复多供应商多账号身份、轮转、独立冷却及凭据持久化，登录成功须确认实际入池。
- 私有JSON包迁移，避免Android framework org.json链接冲突；原目录删除与新目录同批提交。
- 修复入站请求预算、读取期限、异步取消、HEAD正文、持久化、保活与许可资源等问题。
- 补齐WorkBuddy官方账户额度查询、安全续期和账户范围目录。
- 修复MiniMax Code签名身份及分页积分读取，不把未配置M Plan组的有效积分账号报为不可用。
- 接入Qoder官方只读账户额度，区分缺失、未知、企业模式和已知零值；不改变上游排队和一次性刷新保护。
- 用量账本增加实际账号ID归因，不记录账号token或用户ID，不增加强制账号路由接口。
- 同步测试、面板回归脚本、许可证与原证书签名构建说明。

## 当前版本验证

- 九个聚焦JVM/HTTP执行任务通过，包含新增28条MiniMax额度/归因检查和9条Qoder解析断言。
- 面板回归34/34通过。
- Android API34专用测试环境，原证书不卸载31→32覆盖升级，十个已有账号、启用状态、应用UID及管理/推理凭据保留。
- 跳过尚未生效赠送额度的ZCode后，七家供应商九个账号均有可归因的真实200短回复。
- Qoder fast模型通过；另两个已试模型返回上游排队，未伪报成功、盲目重放或更改登录状态。

以上不是全部模型、设备或业务场景通过：未在新版重跑历史全量232任务、真实流式、强制过期/一次性refresh、自动容量切换、国际/团队真实套餐与长时矩阵。Release构建通过并执行lintVital，未单独重跑完整lintRelease。
