# All In 1.2.20 · 厂商后台保活选项

基于正式 1.2.19，收录已交朋友实机反馈通过的后台保活测试版，作为下一阶段开发基准。

- 在「治理 → 权限与保活」加入独立的悬浮窗、静音音频实验开关，默认关闭，展示权限、附着、数据写入和错误状态。
- 仅开启静音音频时申请 mediaPlayback 前台服务类型，保留原 specialUse 网关和恢复机制；音频线程独占资源并顺序释放。
- 补充 OPPO/一加/realme、小米、vivo/iQOO、华为/荣耀后台设置候选入口，失败回退应用详情。
- 复用本地 HTTP 身份健康检查，周期调整为 12 秒；补全 Wi-Fi 权限与低延迟锁。
- 微窗不阻止息屏；不宣称所有厂商均免冻结。朋友实机反馈通过，具体机型、系统版本与长时间耗电记录未取得。
