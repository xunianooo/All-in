# Qoder 工具往返与实时流式（本地功能批）

基于1.2.17/code23继续实现，本批未改版或发布。请求/响应细节对照社区 `@magpie-community/opencode-qoder-auth` 0.2.61 的固定源码；不是自动追踪最新插件。

## 行为

- 请求保留并校验assistant工具调用ID、严格JSON参数、工具结果关联，支持并行调用与普通reasoning_content历史元数据；在通用消息修复前保存Qoder工具历史错误，实际选中Qoder时才拒绝。工具图片按协议移至关联用户内容，原图不下载、不压缩。
- 文本/思考实时转发，Chat、Messages、Responses三入口流式与非流式共享解析与协议转换。原生tool_calls分片及文本JSON/常见XML工具标记支持；工具参数完整、ID/名称/终态验证后才发可执行调用，普通正文可以提前显示。
- 缺失/重复工具ID、畸形/截断参数、混合文本与原生工具编码等明确失败，不自动重发/切目标。代码引用中的工具标签按文本保留；不支持的已识别工具形式明确失败，不假装执行成功。
- 完整finish帧后继续接收usage，直到DONE或完整终态后的干净EOF；无终态/半帧中断失败。length保留，多快照用量按字段合并不重复累加，缺失维度继续未知。
- 保留10605排队分类、Retry-After、输出上限<64本地400、RequestContext取消/deadline、固定长度与禁重定向。有界SSE事件/工具参数各1MiB、非流式聚合8MiB；实时流不因累计文本长度无限增长常驻缓冲。
- 具名会话按稳定账号作用域隔离，同一用户轮次复用task ID/开始时间，成功完成后转processing，新用户轮次创建新task。工具图片续接不另算新用户轮次。无可信会话时随机隔离，task内存限512项/闲置两小时。
- 选中模型必须与本地同步目录key相同，model_config仅发送协议字段，business.model_key明确指定实际模型，未声明is_vl=true不接受图片。模型目录缺失时应先同步。

## 兼容边界

当前tool_choice支持auto/none；strict:true、强制required/具名选择、禁止并行等无法可靠执行的要求发送前明确拒绝。Medium等思考等级依据目录映射，不因客户端默认等级不支持直接400。原生签名/不透明历史继续按原有保护拒绝跨协议转换。

停止网关会取消上游；下游写失败会关闭上游；仅关闭空闲TCP且无后续读写时不承诺立即发现，由既有deadline或显式停止收口。该项未引入自动轮询/自动执行手机工具或内置Agent。

## 验证

集中91离线套件、17独立HTTP任务、17Node脚本通过，含三协议工具结果第二轮、实时门控、并行参数、早/晚错误、零fallback、已知/未知/部分usage、图片、治理上限、原生保护与取消。最后任务信封/图片续轮修订追加定向复验及Debug/Release/lint，0Error/0Fatal/103Warning。Android36无权限独立审计六组通过；末次图片续轮修订由JVM定向再验。

本批未用生产Qoder账号推理，不声称真实供应商端到端、所有模型、完整长期会话、旧Android24/25实机通过。真实端到端交电脑Agent使用账号验证，报告应包含客户端/模型/协议/流式/错误环节，不含凭据或完整用户正文。
