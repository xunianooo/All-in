# All In 1.2.19

本地累计修复与改进统一发布，versionCode 25。

## 供应商诊断可靠性

- 分开解释网络、认证、模型目录、业务错误与实际推理结果；未知状态不当作零或账号整体失效。
- 修复 ZCode gift 型号未覆盖时的空指针、负状态误报成功与未知执行提示；摘要失败不静默切换付费通道。
- Cline 身份、余额和限额分别校验，保留部分有效结果；补齐页面动态数据转义。

## 模型目录与名称

- Qoder 支持有界凭据续期、先安全保存再重读目录、按账号目录合并及路由隔离，同 UID 重新授权更新已有账号。
- Cline 纳入云端完整目录；Codex/Cline 同步失败保留旧目录，不以静态表冒充云端成功。
- 标准目录支持有界分页，后页失败不提交部分结果。
- 页面优先显示官方模型名称，保留实际调用 ID。

## 倍率与订阅信息

- 统一解析官方模型消耗倍率、原价与活动时段；支持 Qoder、Trae、WorkBuddy、小浣熊、妙手等已有来源。多账号不同倍率明确区分。
- 增加按账号展示的额度刷新，区分账户共享、模型剩余比例和赠送单位；缺失、查询失败及旧快照不冒充零或最新状态。
- 妙手动态模型目录携带倍率和类型元数据；MiniMax 保存官方名称与上下文信息，不把上下文窗口当倍率。
- 修复同步成功提示出现 undefined 及 Trae 刷新方法错误。

## 验证边界

发布门禁包括离线及环回 HTTP 回归、23 个独立面板脚本、集成 HTTP 门禁、构建与 lint，并由 Windows/Ubuntu CI 复验。
真实账号验证涵盖 Qoder、Trae、妙手、小浣熊等代表目录与倍率；不代表所有供应商全部模型和订阅额度均已真实账号验收。Codex/Cline/Copilot 的额度路径以合成测试为主。部分额度接口可能不可用，界面保留未知。MiniMax 实时目录上下文与桌面插件静态覆盖值可能不同。

升级保留现有账号及配置，无需卸载。费用估算与内置 Agent 不包含在本版。
