# All In 1.2.41 正式版（47）

**正式发布，不是预发布，并设为 Latest。** 使用已经验收的原证书签名安装包；APK内部版本名和标签保留 `1.2.41-test` / `v1.2.41-test`，没有为了改显示名称重新制作不同的包。

## 相比上一公开版本 1.2.39-test（45）

### 真正的账号 JSON 文件迁移

- 供应商卡片上的导入/导出按钮接入 Android 系统文件选择器和“另存为”，不再把复制到剪贴板当作文件导出。
- 可勾选单个、多个或跨供应商账号/独立 API Key，文件实际写入并读回核验后才显示成功。
- 一份混合 JSON 自动识别并分别入池；支持明确归类、预览、重复跳过及更新确认，不盲目覆盖原账号。
- 保留账号停用、续期、可迁移设备资料及相关刷新/签到保护；本地导入采用独立原子提交，失败不在内存残留新账号。
- 支持已对齐的 All In 标准/历史格式、OpenCode/Magpie 认证字典、Codex auth.json，以及 ZCode、Antigravity、Qoder 特殊结构。

### 供应商界面清理

统一删除 CatPaw、GitHub Copilot、MiniMax、Cline、Codex、Antigravity 共6处“已移植”绿色徽标，连空标签也移除。账号计数和后台能力状态保留，账号 JSON 功能与上一轮修复不变。

## 验证范围

- 46版功能开发时完整249个JVM/本地HTTP执行任务通过，新增迁移180条检查；Android API34运行时36/36及真实系统文件保存→混合导回、重复/取消/故障测试通过。
- 47版仅移除徽标及修改版本展示，业务DEX与已验收46版逐字节相同。真实DOM、安装包和已装网关页面中的“已移植”从6处变0，无空绿色标签。
- 本次发布前再次执行页面回归40/40，重新核对原证书签名及全部打包资源；没有把此前249任务/36项设备测试冒充本次重新全跑。

正式发布级别不代表所有第三方文件格式、所有模型/账号、国际团队、旧系统/OEM或长时场景均已认证。JSON文件含登录凭据，请妥善保管；失效凭据、缺字段或平台硬件绑定仍可能需要重新授权。
