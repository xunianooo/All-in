# All In 1.2.160-test（构建 168）

此版本汇总自 `1.2.158-test`（构建 166）以来的改动。使用原签名，可直接覆盖安装，不用卸载或清除数据。

## 修复

- **账号 JSON 导出**：修复保存窗口已创建文件、却可能留下 0 字节内容的问题。选择保存位置前先检查能否导出；不相关的配置更新和屏幕旋转不再打断保存。若选中的账号或密钥已变化，会提示重新选择，不会导出旧凭据。写入后会回读校验；失败时仅自动清理能确认属于本次导出的本机空文件，其他位置会提示手动处理。JSON 仍包含登录凭据，请保存在可信位置，勿公开分享。
- **请求诊断记录**：手动展开的卡片和底层详情会在刷新、新记录插入、排序变化或状态更新后保持展开；手动收起后，刷新也不会重新打开。
- **WorkBuddy 删号后重登**：旧授权失效时可重新发起授权，不必为了重试换一个手机号码。若官方身份已确认、只是本地保存失败，则只重试保存，不重复获取凭据。模型目录在账号保存成功后再同步，目录慢或不可用不再阻挡入池确认；已移除账号不会被迟到的目录结果恢复。
