# All In 1.2.18

基于 1.2.17 的本地累计更新统一发布，版本号 1.2.18 / versionCode 24。

## 新增与改进

- Qoder 工具声明、调用 ID、JSON 参数与工具结果完整往返，完善 Chat / Messages / Responses 的实时流式及非流式转换、文本工具解析和独立用量维度。
- 为 20 家已支持供应商提供登录前匿名端点探测。根据实际接入地址分别检查网页、认证或 API 服务，显示 HTTP 状态、耗时及 DNS / TLS / 超时等错误；探测不使用账号、不提交推理、不更改模型目录或路由。商业 API 探测限定官方默认地址。
- 完善 Cline、Codex、Copilot、Antigravity 的账号刷新协调、并发配置校验和凭据持久化；完善禁用账号选择、模型目录原子提交和模型测试诊断。
- 更新 WorkBuddy 请求与会话兼容、Trae 字段容错、MiniMax 轮询及错误分类、CatPaw 请求边界、DeepSeek 历史处理与 ZCode gift 账号退避及领取缓存。
- 使用用户提供的新品牌图标，适配多密度、圆形和 Android 自适应图标，并同步面板图标。

## 修复

- ZCode 成功但无 data 的额度活动预览被误判为失败，阻断已有赠送额度查询和调用。现在在明确业务成功时继续读取余额，真实异常仍不静默转用付费 Plan。
- WorkBuddy 目录请求客户端头不完整，以及解析失败后用合成 `auto` 目录覆盖有效模型列表。现在只接受有效的官方 CLI 模型目录，失败保留原模型与元数据。
- 供应商详情页和添加页按 Android 系统返回键直接退出。现在先关闭弹窗或回供应商列表，没有内部页面可返回时再执行原生返回。

## 验证与限制

发布前执行 JVM 离线及本地 HTTP 回归、前端回归、Debug / Release 构建与 lint，并由仓库 CI 在 Windows / Ubuntu 上复验；发布产物需等待这些检查成功后提供。

本地真实验证包括 20 家匿名探测前后配置字节一致，以及 WorkBuddy、ZCode gift、小浣熊代表模型的流式和非流式响应。电脑反馈固定 Accumulated-Providers 包测试无误；此后修复另有定向及真机验证。上述证据不代表所有供应商真实账号、全部模型、完整长工具会话或旧 Android 设备均已验收。

收到 HTTP 响应不等于登录或推理成功，匿名 OPTIONS 的 401 / 403 / 404 / 405 等按明细解释；官方固定探测不代表自定义 base、动态项目或浏览器网络路径。部分海外服务在特定网络下可能超时或受限。Antigravity 原高级探测并切换端点作为独立功能保留。

费用估算、内置 Agent 和 Playground 不包含在本版。配置与账号保持现有应用数据，升级无需卸载。
