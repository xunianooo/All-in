# 账号连续性与模型诊断（本地累计）

在Qoder与上游对照优化累计版上继续，版本保持1.2.17/code23，未提交推送或发布。

## 行为

- Copilot、Antigravity的已存账号令牌刷新统一进入按供应商/稳定账号隔离的协调器。刷新只改候选副本，重新检查账号启用、凭据及配置状态，通过后先原子写盘再发布；同账号不同JSONObject副本的并发调用只交换一次。401恢复时若已有另一请求更新令牌直接复用，不追加无意义刷新。
- 账号被删除、禁用、替换（包括相同内容的新对象）、恢复退役或写盘失败时，不发布旧刷新结果。此处为当前进程的事务控制，不是跨进程刷新journal。
- Qoder、CatPaw、Antigravity推理选择和ZCode gift面板跳过禁用账号；缺省enabled仍按启用。供应商禁用时目录同步在网络前拒绝。
- 模型目录在锁内重新取得当前供应商并原子保存。并发凭据更新得到保留；模型、协议、地址或供应商状态发生冲突时拒绝覆盖，不再显示成功却写入旧对象。
- Antigravity项目发现使用账号副本并校验当前对象和配置状态后提交，避免发现结果写回已替换账号。
- 模型测试保留原有HTTP200结果信封和statusCode，追加localRejection、executionUnknown、errorKind及校验过的retryAfter，不把本地状态冒充独立上游状态。面板展示状态、类别、等待，并转义模型名、回复、错误及提示内容。

## 验证

本轮去重9个相关Java定向套件及3个前端脚本通过；Release构建及Gaeul签名验证通过。覆盖并发单次刷新、保存前不使用候选、删除/禁用/替换/CAS/写盘失败、目录提交保留新凭据、禁用账号选择、模型测试429与连接失败、界面HTML转义。

没有重跑全量回归、远程双CI、lint、Android隔离或真实账号推理。最新包仅覆盖安装并检查配置哈希不变、安装hash、7API及前台服务；不据此声称所有供应商真实端到端通过。空expiry保留已有令牌的既有语义仍在，新增账号登录中的旧辅助网络流程未扩成新架构。用户和电脑Agent将在更大累计节点统一真实账号验收。
