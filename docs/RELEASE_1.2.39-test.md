## 确认与修正

- MiniMax npm0.2.9明确accept-encoding identity，gzip可能在整条回答结束才flush。本机原来没设置，Android默认透明压缩存在同类风险；现明确identity，保持模型输出与用户Guard数值不变。
- Qoder npm0.2.67原生工具名称确定即发起始事件、参数后续增量；本机原来finish才发。现按标准非终态事件增量，文本工具在完整调用识别后可发送；终态仍完整检验JSON/ID/声明/工具选择/截断。非流式聚合按index组装碎片，既不重复调用也不重复参数。
- Qoder原生事件前检查已到达的文本尾部，与源码flush时机对应；保留未知身份、混编、无效JSON等更严格fail-closed保护，不移植模糊回复盲重试。
- Antigravity原来关闭中间管道未即时关闭上游。现下游关闭传播原始响应体、停止转发线程。没有因此新增有风险推理重试；npm Gemini4自身有意的有限思考预读不被误称为文本伪流式。
