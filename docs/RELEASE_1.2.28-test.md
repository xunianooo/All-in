# All In 1.2.28-test（34）Trae 国内版登录修复

本地测试版，未提交或发布。参考固定的本地 Trae 0.2.34 与 2026-11-13 同步的 Magpie 源码，未重新更新上游。

## 修复内容

- 区分“设备绑定”与“网页登录”：两次设备绑定被明确拒绝后，用官方只读账号接口核验现有网页登录凭据；核验通过才入池，不把账号伪标为已绑定。
- 保存回调的 ClientID，为已验证的网页会话补齐普通续期；仍走现有单账号协调、原子比较更新和持久化围栏。
- 使用单次请求传输，完整保留 HTTP401 等错误正文，不经过可能吞正文或自动重试的认证器；复用项目既有严格 HTTP 分帧与 gzip 解析。
- 保留上一版失败状态恢复和脱敏诊断。网络结果不明、无效凭据、异常回包及保存失败均不得伪报成功。
- 不自动签到，不轮换设备身份绕过上游限制。设备绑定未启用时，部分功能仍取决于 Trae 实际权限。

## 验证

- 新增回归在修复前复现截图中的 HTTP400/10101 → HTTP401/20403 入池失败，修复后通过。
- 新增68项检查覆盖网页登录核验、并发单次续期、截断/矛盾回包、无效凭据、持久化失败、多账号保留和未知结果不重放。
- 11个Trae JVM/回环HTTP任务及2个共享HTTP解析相关任务通过；Release Lint通过。
- 上述是合成测试，不等同于反馈手机实际登录通过。真实登录需在原签名升级包安装后人工完成；不要卸载或清数据。
